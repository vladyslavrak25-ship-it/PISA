# PISA: сім'я, школа і розрив у балах

Інтерактивна сторінка за шістьма навчальними дослідженнями PISA (KSE). Один файл `index.html`, без зовнішніх бібліотек (лише шрифти Google).

## Що на сторінці

- **Розрив Q4−Q1** для України, Естонії, Чехії, Польщі та Бразилії, з показниками рівнів 2 і 5+.
- **Дві незалежні роботи, той самий результат**: порівняння роботи 1.1 і звіту про 11 країн ЄС для Естонії, Чехії та Польщі.
- **З чого складається розрив: родина чи школа** (нове). Розрахунок на коефіцієнтах роботи 1.1.
- **Симулятор десегрегації** на реальних коефіцієнтах замість вигаданих ваг.
- **Що працює: освіта, професія чи речі вдома** (нове). Порівняння країн за HISEI, PAREDINT, HOMEPOS.
- **Де на шкалі Україна** (нове). R² для 14 країн із застереженнями щодо даних.
- Що спільного між роботами та де вони не збігаються; таблиця джерел.

## Як рахується розклад розриву

```
SD балів         = розрив ÷ d
власна частина   = 2 × βвл × 1,271 × SD
шкільна частина  = 2 × βшк × 1,271 × √ICC(ESCS) × SD
решта            = розрив − власна − шкільна
```

Це розрахунок сторінки, а не результат самих робіт. Він припускає приблизно нормальний ESCS і причинність зв'язку зі складом школи; це лише зв'язки.
